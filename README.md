## 7주차 실습

## 사용자와 목표
- 사용자: 일상 속 물리학을 탐구하는 사람
- 목표: 일상 속 물리학을 탐구주제를 통해 정하고 내용을 확인한다.

## 사용자의 흐름
1. 탐구 조회 정보 동의하고 '탐구 시작하기'를 누른다.
2. 탐구 주제를 입력한다. 비어 있으면 같은 단계에서 안내를 받는다.
3. 탐구 주제를 선택한다.
4. 탐구 내용을 확인한다.

## 인터랙션 시나리오

## 1. 탐구 설정 시작
- 행동, 이벤트: 탐구 진행 안내 체크박스를 선택하고 '탐구 설정하기'를 클릭한다.
- 조건: 안내를 확인했는가?
- 반응, 다음 상태: 확인하면 버튼이 활성화된다. 클릭하면 안내 팝업이 열리고, 확인 시 탐구 이름 입력 단계로 이동한다.

## 2. 탐구 이름 입력
- 행동, 이벤트: 탐구 이름을 입력하고 '탐구 주제 선택하기'를 클릭한다.
- 조건: 입력한 값이 비어 있는가?
- 반응, 다음 상태: 비어 있으면 오류를 표시하고 입력창에 초점을 둔다. 이름이 있으면 주제 선택 단계로 이동한다.

## 3. 탐구 주제 선택 및 확인
- 행동, 이벤트: 탐구 주제를 선택하고 '설정 내용 확인하기'를 클릭한다.
- 조건: 탐구 주제가 선택되었는가?
- 반응, 다음 상태: 선택하지 않았다면 안내 메시지를 표시한다. 선택했다면 탐구 이름과 주제를 표시하고, 수정하거나 설정을 완료할 수 있다.
