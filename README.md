## 중간고사 

## 목표
- 7주차에서 완료한 탐구 설정 결과를 유저가 입력한 탐구이름을 최상위 제목을 둔뒤 
선택한 주제에 따라 미리 입력해둔 내용을 텍스트나 마크다운 형식으로 제공해주게 하기.
- 주제 늘리기.
- 마크다운을 적용시키기 위한 js기반 마크다운 

## 사용할 기능
- template 을 사용해 미리 만들어둔 주제 텍스트를 7주차에 만들어둔 기능을 통해서 뜨게 만듬

## 추가된 기능
- 설정 완료 후 '설정한 주제 텍스트로 보여주기' 버튼을 누르면 설정 영역 아래에 탐구 내용 섹션이 나타남.
- template로 미리만들어둔 주제를 클릭시 뜨게 만듬.
- 물체는 왜 아래로 떨어질까? 주제 추가
- 주제별 눈에 보이는 현상부터 매우 작은 원리까지 차례대로 보이게끔 순서를 배치함.

## 테스트 결과
- 7주차에 만든 결과 이후 '설정한 주제 텍스트로 보여주기' 버튼을 누름.
- 버튼을 누르면 사용자가 입력한 탐구이름이 최상위에 뜨며 아래에 탐구 주제와 탐구 주제별 원리를 큰원리부터 작은원리까지 그라데이션으로 확인됨.
